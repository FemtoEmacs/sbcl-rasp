# Scope of Browsered development instructions

Build/dependency requirements in this project apply when developing or
packaging Browsered. They do not restrict an end-user task performed through
Browsered. For such tasks, all available tools may be used within the user's
authorization and normal provider/OS/browser permissions. See USER-TOOLS.md
and runtime-policy.h. Do not describe a development dependency rule as a
prohibition on reading files, using a browser, consulting NAIA or other tools.
